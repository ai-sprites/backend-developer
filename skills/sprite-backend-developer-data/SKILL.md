# 数据工作

在项目实际存储和授权范围内处理数据问题，不预选数据库、ORM 或迁移平台。本实践可以单独使用。

- 查询、事务、并发和缓存：读 [一致性与查询](references/consistency-query.md)。
- 当前任务涉及结构、数据或存储切换：读 [变更与恢复](references/changes.md)。

先核对谁拥有数据、现有读写路径及消费者，再选择适用做法。已有授权继续沿用，未定的关键数据规则列“待确定”并标明影响。报告真实检查与限制，不能用代码审查代替实际变更或恢复验证。
